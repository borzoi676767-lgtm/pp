# Milites Christi

*"Soldiers of Christ"* — a premium Christian heritage brand.

Look & feel: late-Roman / Early-Christian imperial — black and Carrara marble, aged
bronze, deep burgundy and olive, warm candlelight, and the **Chi-Rho** as the central
motif. The goal is the feeling of entering a 1,700-year-old basilica: timeless, sacred,
majestic, hopeful. History inspires the aesthetic; Christ remains the message.

## The master build prompt

Everything for building this brand as a premium **Shopify** theme lives in a single,
self-contained, Fable-5-optimized Claude Code prompt:

- **[`milites-christi/BRAND-PROMPT.md`](milites-christi/BRAND-PROMPT.md)**

It consolidates the full brand bible, theological/ethical guardrails, historical and
artistic foundation, visual DNA, design system (color, type, materials, iconography,
motion), Shopify OS 2.0 theme architecture, section/component library, copy and SEO,
accessibility and performance budgets, media direction, coding standards, acceptance
criteria, and an expansion roadmap.

To use it: paste the file's contents into Claude Code (Fable 5), or point Claude Code at
the file and ask it to build the theme accordingly.
